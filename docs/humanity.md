# 大家好，我是 Domirus

你知道 WhatsApp 是什么吗？它是一个用来和人聊天的应用。它安全吗？安全。但它真的稳定吗？如果我被困在亚马逊森林，我还能打电话给家人吗？不一定能。

让我们想象一下：世界被外星人入侵了。火山爆发。所有的电塔都倒了。我们陷入一场打不赢的战争。你找到你的手机。你解锁它。你想打给你奶奶，告诉她你还活着。然后你发现——打不通。手机只是发出“嘟——”的声音。什么也没发生。你发消息给朋友，但我们的 5G 网络已经消失了。以前我们能用 80 毫秒的延迟打游戏，现在我们连一条消息都发不出去。很可怕吧？作为一个依赖互联网的人类，我们会崩溃。没有 YouTube，没有 Instagram，没有 Facebook。

好，我们回到这个舒适的世界。你怎么看刚才那个场景？当外星人入侵时，我们可能不想看 YouTube，但我们需要联络父母和家人。那怎么办？

这就是 Numotirus 存在的意义。你之前听说过 Numotirus 吗？实际上，它是一个不需要互联网就能通信的协议。也就是说，如果你被困在亚马逊森林、被外星人攻击，或者更糟——你只需要你的手机，我们就能让你和家人通信。它像是一个看得见的东西。我们怎么在没有互联网的情况下互发消息？嘿嘿，那你就需要自己去找答案了。如果你好奇，欢迎你来一起贡献。

这是一件有点危险的事情，因为我们的隐私保护做得很好，坏人和恐怖分子可能会用它来做不好的事。但这重要吗？不重要。我们会帮你确认，和你说话的人确实是你想说话的那个人。

如果你需要一种和好朋友保持联系的好方式，你可以考虑 Numotirus。因为在危险的时候，它可能救你一命。怎么救？你自己去找答案，我相信你。

今天就到这里。谢谢。
