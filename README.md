# Numotirus —— DETAILED 分支

**中文版 | [English](./ENG_README.md)**

这不是一个普通的代码分支。它是 Numotirus 的"学习版"。

---

## 为什么有这个分支？

`main` 分支的代码是相当复杂的。它跑得起来，但它没有告诉你"为什么这样写"。

`DETAILED` 分支是我（Domirus）逐行读代码时，把自己的理解写成注释的地方。它的目标是：**让下一个看不懂的人，能从这里找到答案。**

这个分支不是写给"专家"看的。是写给"想学但不知道从哪看起"的人看的。

---

## 它不是什么

- ❌ 不是"官方文档"——这里的注释是个人理解，可能有偏差
- ❌ 不是"最终答案"——这里的注释会随着我的理解加深而更新
- ❌ 不是"生产环境"——这个分支是用来学的，不是用来跑的

---

## 它是什么

- ✅ 是**学习笔记**——每一行注释都代表"我当时这样理解"
- ✅ 是**路标**——如果你看不懂某段代码，这里的注释可能刚好帮你打开思路

---

## 怎么用

```bash
git checkout DETAILED
```

打开 `core/crypto/crypto.cpp`，从 `derive_key` 开始看。

**注释格式：**

- `// DOMIRUS:` —— 我写的理解
- `// AI:` —— AI 生成的解释（留存参考）
- `// TODO:` —— 还没搞懂，先放着

## 如何参与

如果你也在读 Numotirus 的代码：

1. 切到 `DETAILED` 分支
2. 在你读懂的代码旁加上注释（格式：`// [你的名字]:`）
3. 提交 PR
4. 审核通过后合并

不需要你写 C++ 代码，只需要你写下"我理解了什么"。
