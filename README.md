# Numotirus – AI 分支（原始代码存档）

---

## 目的

此分支包含 Numotirus 项目最初由大语言模型（LLM）生成的原始代码。此处存档，供 **参考、研究及学习用途**。

此代码 **不适合用于生产环境**。

---

## 背景

Numotirus 项目始于一个实验：*大语言模型能否设计并实现一个安全的、去中心化的、端到端加密通信框架？*

此分支即为该实验的产物。

项目维护者在评估后认为，此代码需要进行完全重写，才能达到项目对安全性和可靠性的要求。当前由人类主导的 Numotirus 版本位于 `main` 分支。

---

## 观察发现

对代码库的审查揭示了 LLM 生成软件的若干典型特征：

- **表面完整度较高** — 代码可以编译，模块结构清晰，API 有文档说明。
- **大量采用最佳实践模式** — 代码使用了标准的加密原语、命名规范和模块化设计。
- **深层存在显著问题** — 安全关键逻辑中存在有经验的人类审查者能够发现的漏洞。

---

## 审查中发现的主要问题

| 领域 | 观察到的现象 |
| ------ | ------------- |
| 密钥管理 | 共享秘密以明文形式存储在磁盘上 |
| 加密配置 | 预期应可配置的参数被硬编码 |
| 协议集成 | 两套独立的加密系统被不一致地混用 |
| 功能实现 | 部分组件仅以占位符形式存在 |
| 审计记录 | 附带的审计报告由生成代码的同一 AI 模型完成 |

这些问题并非孤立错误，它们反映了当前 LLM 在处理复杂且对安全性敏感的软件工程任务时的局限性。

---

## 此分支是什么

- LLM 在构建复杂系统时产出结果的一份记录
- 供研究人员研究 AI 生成代码的参考材料
- 评估 AI 辅助软件开发进展的一个基线

---

## 此分支不是什么

- 一个可工作的或安全的实现
- 项目当前方向的体现
- 任何形式的推荐或认可

---

## 对研究者的说明

如果你正在研究 LLM 生成的代码，此分支可作为一份有用的数据样本。代码覆盖了多个模块，包含实现和文档，结构相对完整。

---

## 与主项目的关系

- **`main`**：当前由人类主导的重写版本 — 正在积极开发中，经过安全审查
- **`AI`**：原始 LLM 生成的代码 — 存档备查，不再维护
